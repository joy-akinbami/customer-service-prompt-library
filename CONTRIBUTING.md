# Contributing to the Customer Service Prompt Library

Thank you for your interest in contributing to this project! 🎉

This repository is a collection of reusable, tested prompt templates for common customer service email scenarios. The goal is to build a high-quality resource that demonstrates prompt engineering best practices while helping others create professional, empathetic, and consistent AI-generated customer communications.

## How to Contribute

Contributions of all sizes are welcome. You can help by:

- Adding new customer service prompt templates.
- Improving existing prompts for clarity, tone, or effectiveness.
- Expanding documentation or examples.
- Fixing typos, formatting issues, or broken links.
- Suggesting new customer support scenarios.

## Prompt Format

To keep the repository consistent, each prompt file should follow this structure:

```markdown
# Prompt Title

## Purpose

Briefly explain what the prompt is designed to accomplish.

## Prompt

Provide the reusable prompt template with variables.

## Variables

List and describe each placeholder variable.

## Why this prompt works

Explain the prompting strategy and reasoning behind the structure.

## Example Input

Provide sample values for each variable.

## Example Output

Include a sample AI-generated response that has been tested and refined.

## Notes

Add implementation tips, limitations, or customization ideas.
```

## Contribution Process

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your updates following the existing format.
4. Test your prompt to ensure it produces high-quality, consistent results.
5. Commit your changes with a clear commit message.
6. Submit a Pull Request describing your contribution.

## Writing Guidelines

Please ensure that prompts:

- Use professional, respectful, and empathetic language.
- Avoid biased, offensive, or inappropriate content.
- Are reusable by using placeholder variables.
- Produce concise, actionable, and customer-focused responses.
- Include at least one tested example output.

## Reporting Issues

If you find a mistake or have suggestions for improvement, please open an Issue describing:

- The problem
- The affected file(s)
- Your suggested solution (if applicable)

## Code of Conduct

Please be respectful and constructive when contributing. Feedback should be professional, inclusive, and focused on improving the quality of the project.
