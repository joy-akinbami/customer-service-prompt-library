# Customer Service Prompt Library

   A collection of tested, reusable prompt templates for common customer 
   service email scenarios, refined through iteration to produce 
   professional, empathetic, and on-brand responses.

   [1-2 sentences on the problem this solves]

   ## Prompts included
   - Handling an angry/frustrated customer
   - Following up on an unpaid invoice
   - Onboarding a new client
   - Apologizing for a delayed delivery
   - Requesting a testimonial or review
